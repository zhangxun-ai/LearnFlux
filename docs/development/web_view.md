# Web 结果页与学习页

提交任务后，使用返回的 `view_token` 打开 `/view/{view_token}`。结果页展示处理进度、AI 解读和原始或已校对的正文。进入 `/study/{view_token}` 后，可围绕同一份资料做笔记、提问或查看图解。

- 任务状态、结果和原始资料按当前存储配置保存。浏览器里的近期任务只是入口。
- 学习页、对照和图解接口先核验资料归属。飞书原文还会核验配置的本机读取身份。
- 原文导出见[原始内容导出](../features/raw_export.md)。开启飞书归档后，可在结果页查看交付状态，并把选定图解追加到同一篇飞书文档。

企业微信通知已退役。飞书机器人通知和知识库归档是独立功能，分别见[通知说明](../guides/notification.md)和[飞书归档](../guides/feishu-archive.md)。
