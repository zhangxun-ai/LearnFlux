# 自动保存解析结果到飞书知识库

> 版本说明（2026-10-23）：独立归档、去重和创建后回读已在 `main` 提供。本指南同时记录最新开发版的同文档更新、富内容保护、链接校验修复与结果页交付状态；这些增强的代码尚未合入 `main`。配置前先核对当前分支，不能仅凭文档判断接口或新状态已经可用。

本地工作台负责解析，独立后台服务每 30 秒读取已完成任务，将 AI 解读和完整校对正文写成一篇飞书原生文档。手机直接在飞书阅读，已保存的文档不依赖 Mac 在线。

## 配置和运行

复制 `config/feishu_archive.example.json` 到私人配置目录，设置实际 CLI 路径、知识空间 ID、目标 Wiki 节点、状态数据库路径和启用时间 `since`。使用 CLI 已授权的用户身份，不复制飞书访问令牌。`users_file` 与 `api_user_name` 指向已有本地 API 用户；文件权限应只允许本人读取。

`since` 按任务创建时间限制导出范围，必须显式设置为启用时间，避免批量上传所有历史数据。仅当需要导入指定已有任务时设置 `include_task_ids`。任务必须已成功且解读、正文均可读取；如果没有校对稿，使用完整原始转录并标明状态。纯 JSON 原始转录会原样保存，主流程优先使用可读的校对正文。

在仓库根目录运行：

```bash
uv run python scripts/feishu_archive_worker.py --config /absolute/path/config.json --once
uv run python scripts/feishu_archive_worker.py --config /absolute/path/config.json
```

macOS 可用单独的 LaunchAgent 托管第二条命令：工作目录设为仓库根目录，设置 `RunAtLoad`、`KeepAlive` 和包含 Node、uv、CLI 的 `PATH`，日志写入私人目录。它在用户登录后运行，不需要保持网页打开。锁屏本身不停止进程；电脑休眠、关机、退出登录或断网会影响处理。恢复在线后会重新扫描指定时间范围的已完成任务。

## 完整性与重试

- 每份结果使用“目标节点 + 稳定 view 身份”去重；重复提交命中同一缓存时不会重复建文档。
- SQLite 保存导出状态及生成正文，进程重启后继续。它只存导出记录，业务内容仍以工作台持久化存储为准。
- 创建后回读全文，逐段文本归一化比较通过才标记 `done`；不能用 HTTP 成功或只核对标题代替完整性检查。
- 创建成功但回读失败时，仅重试回读已有文档。明确的授权拒绝可在授权恢复后重试创建。
- 创建超时、进程中断或未知写入结果进入 `uncertain`，先列出目标节点并查找标题及完整正文均匹配的文档。查不到时不盲目新建，保留记录供核对；只读临时故障会退避重试。
- 新记录保存已确认写入版本和远端富内容摘要。重新校对后，仅当原生成内容、富内容摘要及远端版本均可核对时更新同一文档；更新使用飞书基准版本，避免覆盖并发编辑。用户新增文字、图片或格式时暂停更新并显示需核对。升级前没有可信富内容基线的记录保持保守，不自动认领为可覆盖内容。
- 更新超时后先读取已有文档核对；正文匹配可确认交付，但未知写入结果不能凭正文相同就认领用户后续添加的富内容。保留原文，不重复创建文档。
- 链接比较同时核对可见文字和目标地址，兼容原文 Markdown 链接转为飞书原生链接；链接丢失或目标改变不能视为完整。
- 新文档不重复插入本地 API 的导出元信息。旧记录进行版本判断时忽略已知的动态导出日期头，避免隔天重复判定为内容更新；完整读回校验仍严格核对实际保存的全部正文。
- 原始内容中的 XML、图片、附件等不会被当作上传指令执行。AI 解读保留标题、列表等基础格式；远端图片仅保留描述，表格保留文本结构，不上传音视频原件。

结果页显示飞书交付状态、打开文档和安全重试。读取状态与重试只访问本地导出记录；不阻塞解析，不在页面请求中调用飞书。仅任务所属用户且同时匹配归档配置身份可访问。接口为 `GET /api/tasks/{task_id}/delivery/feishu` 与 `POST /api/tasks/{task_id}/delivery/feishu/retry`，重试只清除退避时间，保留未知创建/更新状态供后台对账。

API 默认读取私人配置 `~/.config/learnflux-mobile/feishu/config.json`，其他部署可通过 `LEARNFLUX_FEISHU_ARCHIVE_CONFIG` 指定同一配置文件。未启用归档或用户身份不匹配时不显示交付行。

`exports` 表包括 `pending` / `creating` / `uncertain` / `verifying` / `done` / `update_pending` / `updating` / `conflict` 状态，并记录 `document_url`、`attempts`、`last_error`、`next_retry` 和版本基线。旧表仅追加列，保留现有记录。日志只输出计数或错误类型，不输出授权信息、私有结果链接和正文。

暂停此 LaunchAgent 即停止后续自动保存；无需删除本地结果或已经创建的飞书文档。修改目标或启用时间后重启导出服务。知识库权限保持用户现有设置，不自动开放分享。
