# 读取飞书文档进行深度学习

> 开发中（2026-10-23）：本文对应本地开发工作区中的文档读取实现，尚未合入 `main`。本次仅发布使用文档；请先确认当前分支包含 `document_sources/feishu.py` 及相应路由，再按本指南配置。

单篇学习支持飞书与 Lark 的 HTTPS `/wiki/`、`/docx/` 文档链接。正文通过本机已登录的 `lark-cli docs +fetch --as user` 读取，进入文字解读流程，不调用音视频下载器或 ASR。分享查询参数和选区锚点不改变文档身份，读取范围始终为全文。

## 本机配置

先安装并登录官方 Lark CLI，确认当前账号能够读取目标文档。在私人 `config/config.jsonc` 中设置：

```json
"feishu_documents": {
  "enabled": true,
  "cli_path": "lark-cli",
  "owner_user_id": "legacy_user",
  "timeout_seconds": 60
}
```

服务进程找不到 CLI 时，将 `cli_path` 设置为实际可执行文件路径。`owner_user_id` 必须与任务所属身份一致；兼容管理身份及同身份的手机入口通常为 `legacy_user`，其他用户应填写实际身份。该检查先于正文缓存读取，其他 API 用户不能借用本机飞书账号读取文档。默认关闭此能力，共享/在线部署不应直接复用个人账号。

修改后重启本地服务。未登录、无权限、超时、正文为空或只返回文档片段时，任务会失败并显示原因，不回退到音视频处理。

## 内容边界

保留正文、标题、Markdown 结构与图片引用。图片、画板等未展开的视觉内容会明确提示，不将文字读取当成 OCR 或视觉理解。结果页同时显示读取范围。CLI 的内容降级提示也会随结果提示。

完整原始 JSON（含原文、版本及 `reference_map` 等返回字段）写入配置的 `storage.source_files_dir` 下的 `feishu/` 目录；没有配置时使用 `data/source_files/feishu/`。按响应内容哈希保存快照，目录及文件使用私人权限，不覆盖旧快照。这些内容属于用户数据，不进入 Git。

此能力只读取飞书。结果是否自动归档仍由另行配置的归档服务控制。
