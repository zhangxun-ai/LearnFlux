# 手机快捷指令提交到本地工作台

手机通过 HTTPS 调用现有 `POST /api/transcribe`，本地服务接收后进入后台队列；无需飞书或云端 Agent 扫描消息。公网入口不会增加可解析的平台范围。

## 接入与身份

- 将 Cloudflare Tunnel 的指定子域名指向本机实际监听地址，例如 `http://127.0.0.1:8000`。
- 仅用于收集时，隧道只放行精确路径 `^/api/transcribe$`，其余路径返回 404。不要直接公开目录浏览、设置或文件操作接口。
- 在本机 `config/users.json` 中配置独立随机 Bearer Token，并限制文件权限。沿用现有资料库时，令牌的 `user_id` 必须与网页使用者一致；管理口令的兼容身份是 `legacy_user`。
- 独立 Token 本身不等于仅有提交权限；公网路径限制由隧道承担。密钥不要写入本指南、快捷指令分享链接、截图或日志。
- 修改用户配置后需要重启服务。重启前检查是否存在正在执行的任务。

## 本机免口令

个人 Mac 同时配置手机 API 令牌时，在 `api` 配置中开启 `browser_local_auto_login` 和 `browser_local_management_access`。本机直连 `localhost` / `127.0.0.1` / `::1` 的同源浏览器会自动建立管理会话，过期或服务重启后自动恢复，沿用管理身份及原历史资料。手机令牌仍独立鉴权。远程 Host、代理转发及跨站请求不会触发免登录；共享机器上的其他本地使用者也可访问管理功能，因此多用户部署默认不开启该选项。关闭 `browser_local_management_access` 并重启可恢复原多用户登录要求。

## 快捷指令

快捷指令只负责把剪贴板中的链接快速提交给工作台，保留五个动作：

1. 获取剪贴板。
2. 从剪贴板获取 URL。
3. 从 URL 列表获取第一项。
4. 使用“获取 URL 内容”向 `https://<已配置的域名>/api/transcribe` 发 POST 请求。
5. 显示固定通知“快捷指令已执行”，随后结束。

请求头沿用 `Authorization: Bearer <手机令牌>`、`Content-Type: application/json` 和 `User-Agent: LearnFlux-Mobile/1.0`。JSON 请求体的 `url` 引用第三步的“第一项”变量，`transcription_strategy` 保持 `local`。

无需解析返回字典、读取 `message`、匹配状态码或等待转录完成。最后的固定通知只表示快捷指令已执行，不代表后台解析已完成。工作台受理后负责后台处理，处理进度和结果在工作台查看。请求本身发生网络错误时，由快捷指令系统报告。

接口响应 JSON 中的 `code=202` 表示任务受理，不代表转录完成。移除响应读取步骤能避免任务已受理后又因通知或字典转换而显示失败，但不会解决入口断连或后台处理故障。

修改已有快捷指令应保留名称和标识，避免影响手机上已配置的触发入口；Mac 上保存后仍需通过 iCloud 同步到手机。`local` 仅选择本地转录策略，后续 AI 解读仍按工作台模型配置执行。

## 后台运行与验证

- macOS 使用 LaunchAgent 管理服务；`RunAtLoad` 表示登录后启动，`KeepAlive` 用于进程退出后重启。复用已有启动项，避免重复监听同一端口。
- VPN 虚拟网卡可能影响隧道出站连接。遇到 QUIC 超时或 HTTP/2 TLS EOF 时，先排查网络；本机实测通过 HTTP/2 并绑定物理接口的 IPv4 地址可连接，启动脚本应读取当前地址，避免写死 DHCP 地址。不要关闭 TLS 校验或擅自修改全局 VPN 规则。
- 登录后自动启动不等于关机、合盖或休眠后仍在线。没有云端收件箱时，离线提交会失败，需要重新提交。
- 依次验证：本地令牌鉴权、公网无凭据拒绝、公网有效请求受理、本地任务进入终态和结果可读、公网非收集路径返回 404。
- 验证可以使用已有完整缓存的视频，避免额外下载或模型费用；需明确这验证的是公网提交及缓存处理链路，并非新视频转录质量。
- 最后用手机移动网络测试快捷指令。电脑访问公网域名成功不能代替手机实测。

公网仅开放收集接口时，域名首页返回 404 是预期行为，结果在本地工作台查看。

## 停用与恢复

暂停隧道的 LaunchAgent 即可停止公网入口，保留本地工作台。停用手机令牌时，将对应用户配置的 `enabled` 设为 `false` 并重启服务。不要删除资料库、已有任务或其他用户配置。

具体机器上的隧道凭据、启动项路径和验证记录保存在本机运维配置中，不进入仓库。
