## 内容来源与展示方式

公开资料的标题、作者与链接在 [案例数据](../../../scripts/readme_cases.py) 和 [manifest.json](manifest.json) 中列出。演讲和文章的中文解读由人工编写，用于展示阅读效果；整理稿有明确说明，不冒充原话、自动转录结果或真实模型调用。日报展示同一组公开资料的阅读摘要，不冒充当日新发布的新闻。

《背影》等作品采用公版中文原文，未使用现代改写或受版权保护的译本。书架格式如实使用 Markdown；截图不代替各种文件格式的导入验收。

咖啡店案例和生活日记均为原创演示内容，不是用户的私有课程、经营数据或真实日记。播放器使用项目原有插画制作的 45 秒静态演示短片，配合原创文稿；点击第三段后实际跳到约 00:16，不是 Karpathy 的演讲视频或 ASR 实测。

截图服务器不读取应用配置、数据库、聊天成品或私人笔记。生成与删除接口禁用，未知接口不会转发给真实后端。结果页保留应用已有的固定目录状态；没有添加截图专用页面样式。

## 重新截图

在项目根目录准备应用依赖、Node.js / npx、FFmpeg、`cwebp` 及 Playwright CLI 可用的 Chromium，运行：

```bash
uv run --no-sync python scripts/capture_readme.py
```

脚本使用 `@playwright/cli@0.1.23`，首次可能需要访问 npm。它会启动临时本机端口和独立浏览器会话，截图后关闭。PNG、演示视频和日志位于忽略提交的 `output/playwright/readme-20261103-cases/`，WebP 位于本目录。旧截图保留。

本组 9 张图片共 1,070,748 字节（约 1.02 MiB），统一使用 1440 × 1000、浅色主题和 280px 侧栏。图片压缩后应逐张检查文字、日期、封面、正文和播放位置。[manifest.json](manifest.json) 记录资源版本、资料与采集脚本的 SHA-256、来源和每张图片的大小与 SHA-256。
