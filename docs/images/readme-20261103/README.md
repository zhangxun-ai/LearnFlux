## 内容来源

- 标题、正文、课程、日记、报告和示例解读均为本次编写的演示内容，不含真实用户资料。
- 演示服务器只使用内存中的固定响应，不加载应用配置、数据库或外部模型。未知接口没有真实后端回退，处理与删除接口被禁用。
- 示例解读是手写的展示文本，不能作为模型生成质量或真实调用成功的证据。
- 书架展示 Markdown 示例，不以截图证明 PDF / EPUB / DOCX 的实际导入验收。
- 播放器使用项目原有阅读插画制作的 8 秒静态演示视频，分段时间和文稿为手写；点击第三段后实际跳到约 00:03。不是外部课程视频或 ASR 识别结果。
- 日报正文是手写 HTML 示例，装载在真实报告阅读器中，不是本次采集的新闻或私聊日报。
- 结果页使用应用已有的固定目录状态。网络字体使用系统回退字体，避免截图依赖外部网络；没有改造截图专用页面样式。

## 重新截图

在项目根目录、安装应用依赖后，准备 Node.js / npx、FFmpeg、`cwebp`，以及 Playwright CLI 可用的 Chromium。

```bash
uv run --no-sync python scripts/capture_readme.py
```

脚本使用固定版本 `@playwright/cli@0.1.23`，首次可能由 npx 下载；维护者需要能访问 npm。它会启动独立的临时本机端口和浏览器会话，截图后关闭；不会连接正在运行的 LearnFlux。PNG、演示视频与日志保存在忽略提交的 `output/playwright/readme-20261103/`，压缩图写入本目录。也可用 `--output <目录>` 输出到新目录。

界面或样式改变后，先运行 `uv run python scripts/sync_product_navigation.py`，再截图、逐张查看，核对移动端与深色主题。不要只更新图片却保留不同版本的代码。

[manifest.json](manifest.json) 记录资源内容版本、演示资料与采集脚本的 SHA-256、各图来源页面、大小和 SHA-256。自动采集检查页面脚本错误和本地请求失败；本组采集两项均为 0。截图工具不代替真实安装、转录或模型调用验收。
