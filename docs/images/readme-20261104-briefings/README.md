截图反映维护者配置了自己的日报来源与 Codex 定时任务后的页面状态。新安装不会附带这些报告、聊天资料、来源项目或两项定时任务；截图也不代表每一期都无人值守成功。日报读取、权限与手动外部保存见[接入指南](../../guides/daily-briefings.md)。

原始未处理截图、原姓名/群名、完整报告、私有配置和个人自动化提示词都不进入仓库。清单只保存输入哈希、输出哈希、尺寸、替换区域与校验结果，不记录原姓名或本机路径。
