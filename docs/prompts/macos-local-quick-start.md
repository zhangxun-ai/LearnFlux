# macOS 本地快速启动提示词

把下面的提示词交给能访问本机终端的编程 Agent。它会先检查环境和仓库说明，再安装缺少的基础依赖、准备配置并启动 LearnFlux。

```text
你负责在我的 macOS 电脑上启动本地 LearnFlux。请直接检查并完成可以安全自动化的步骤，直到服务可打开；遇到需要我提供密钥、选择付费服务或确认高影响系统变更时，再暂停并说明原因。

## 开始前

1. 找到 LearnFlux 仓库根目录，先阅读 AGENTS.md、README.md 和 scripts/bootstrap.sh，按仓库当前说明操作。
2. 检查 macOS 版本、CPU 架构（Apple Silicon 或 Intel）、磁盘空间、Python、Git、uv、Homebrew、FFmpeg、配置文件和服务端口占用情况。不要输出或读取真实密钥的值。
3. 先检查工作区状态和现有配置。保留用户已有文件、配置和数据；不要覆盖配置、清理目录、重置 Git 状态或删除内容。

## 安装和配置

1. 如果缺少 Homebrew，先说明它是安装 FFmpeg 的系统包管理器，并给我官方安装页面；等我确认后再安装。不要使用 sudo 或来源不明的安装脚本。
2. 以仓库的 `bash scripts/bootstrap.sh` 作为基础依赖安装入口。脚本会按需准备 uv、FFmpeg、Python 依赖，并且仅在配置文件不存在时创建配置。
3. 检查 `config/config.jsonc`。若不存在，使用仓库脚本创建；若已存在，只报告缺少哪些必要字段，不要覆盖。仅将模板中的 `api.auth_token` 占位值替换为安全随机值；不要把密钥打印到终端、聊天、日志或截图。
4. 本地首次使用只需设置 `api.auth_token` 即可启动。大模型 API Key 用于 AI 校对、总结、问答和图解；TikHub API Key 仅在使用抖音、小红书等需要 TikHub 解析的来源时需要。请把待填字段名称和官方申请页面给我，由我在本机私下填写，不要索取或回显密钥。
5. 识别当前配置和我想使用的转录方式。Apple Silicon 可选本机 mlx-whisper；如果它是首选且尚未安装，先说明会下载额外依赖和模型及预计占用空间，得到确认后运行 `bash scripts/bootstrap.sh --with-local-whisper`。若配置使用 CapsWriter，检查 `ws://localhost:6016` 是否可连；服务未安装时，查阅 CapsWriter-Offline 官方仓库的 macOS 说明，告诉我安装步骤和资源要求，再按我的确认安装。FunASR 仅在我需要说话人识别时配置。不要为了启动而安装无关 ASR 服务。
6. 不要配置企业微信、飞书、PostgreSQL、S3、云端 ASR 或其他可选集成，除非我明确提出需要。

## 启动和检查

1. 确认必要配置已经填写；如果缺少 API Key，先启动服务并说明哪些 AI 功能暂不可用，不要编造密钥。
2. 使用仓库支持的命令启动服务，优先按 `./server.sh start` 操作。先确认配置文件中的服务端口（默认 8000）没有被其他进程占用；若已占用，查明进程并告诉我，不要擅自结束它。
3. 访问 `http://localhost:<服务端口>/health`，确认响应中的 `status` 为 `healthy`，再在浏览器打开本机 LearnFlux。检查失败时查看本次启动日志，遮盖凭据后再报告错误。
4. 以一段不含隐私的短文本说明首次使用流程；如使用公开链接，只选免费的字幕或已配置的本机转录路径。不要未经确认提交付费转录请求，也不要上传我的本地媒体。

## 完成时汇报

- 已检查的系统和仓库状态；不要包含密钥值。
- 本次安装的依赖及其用途；已存在或跳过的依赖。
- 服务地址、健康检查结果和首次使用入口。
- 仍需我手动填写的配置字段及对应官方页面。
- 如果任何步骤未完成，说明具体原因和我需要执行的下一步。
```
