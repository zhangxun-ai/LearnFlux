## 检查失败的处理

| 原检查问题 | 处理 |
| --- | --- |
| 3 项首页检查要求已移除的旧卡片 / 文案 | 对齐现有单一导入入口，保留输入方式、原文能力和导航检查 |
| 2 项系列检查缺少播放器入口 | 恢复条件入口，覆盖可用源与不可用源 |
| 1 项把互斥页面状态的 H1 当作同时显示 | 检查当前状态实际可见的唯一 H1，并验证状态切换 |

扩大到默认离线套件后，另发现旧资源版本断言、退役的趋势雷达模板假设、旧图标引用，以及多用户测试中“无所有者资料却由指定用户访问”的夹具问题。已按实际资源版本、临时模板、当前图标和明确所有者修正；未放松生产权限或恢复退役页面。导航生成检查在样式更新后重新同步并通过。
