# 知识地图 UI 功能参考

## 目标

知识地图是学习内容的结构导航层，不是摘要换皮。它帮助用户快速回答：

1. 这个视频或文档核心讲了什么。
2. 这个内容对我有什么用。
3. 我要复看某个观点时，如何直接跳回原视频时间点或原文段落。

## 页面范围

- 系列深度学习详情页：新增 `知识地图` tab，默认优先展示。
- 集合地图：展示系列下各 source 的主干关系和核心贡献。
- Source 地图：展示当前视频/文章内部结构。
- 节点详情面板：展示节点解释、用户价值、证据摘录、跳转入口、复制笔记。
- 状态页：生成中、低置信度、无锚点、空状态。

## 核心交互

1. 用户进入系列详情页，默认看到集合地图。
2. 用户点击左侧 source，进入该 source 的知识地图。
3. 用户点击地图节点，右侧展示：
   - 节点讲什么；
   - 对用户有什么作用；
   - 证据摘录；
   - 跳到视频时间点或原文段落；
   - 复制为笔记。
4. 用户可在 `集合 / 当前 source` 间切换。

## 地图生成规则

- Source 地图默认 5-9 个节点。
- 集合地图默认 5-12 个节点。
- 节点标题必须贴近原内容，不使用固定泛化模板。
- 每个节点必须绑定证据：视频时间段或文档段落。
- 地图类型由内容自动判断：
  - 教程型：步骤路径图；
  - 观点论证型：论点-证据-结论图；
  - 访谈型：主题分叉图；
  - 故事/历史型：时间线图；
  - 方法论型：概念关系图。

## MVP 优先级

第一期优先把 source 级知识地图做好：

1. Source 地图生成和展示。
2. 节点点击显示详情。
3. 节点跳转到视频时间点或原文段落。
4. 集合地图作为轻量入口，展示 source 的核心贡献。

暂不做复杂编辑器、手动拖拽布局、多人协作、复杂缩放画布。
