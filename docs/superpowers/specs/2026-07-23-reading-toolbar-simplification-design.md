# 心流阅读工具栏精简设计

## 目标

将心流阅读的顶部工具栏精简为高频且真实可用的阅读动作，移除功能不完整、含义不准确或没有可见结果的入口；保留背景音的快捷切换。正文分页、目录、全文搜索和既有阅读偏好继续可用。

## 已确认的布局

桌面端工具栏从左到右为：

1. 返回书架。
2. 目录。
3. 居中的文档标题；过长时截断显示。
4. 全文搜索。
5. 背景音快捷入口。
6. `Aa` 阅读设置。

页面两侧保留上一页和下一页翻页按钮。底部仅显示当前页范围和总页数，不提供首页、尾页或指定页跳转。

## 操作与状态

### 背景音

背景音入口保持独立，方便在阅读时切换。打开后显示雨夜、溪流、雪夜以及现有音量控制：

- 选择音轨后立即切换，并延续现有偏好保存行为。
- 已播放时，工具栏图标显示可辨识的活动状态；暂停或未选择音轨时不显示该状态。
- 不新增音频资源、数据模型或后端接口。

### 阅读设置

`Aa` 面板继续包含字号、主题和单页/双页版式。背景音不迁入此面板，避免降低切换效率。

### 删除的入口

- 删除“重新结构化解析 PDF”按钮：尽管其可发起请求，但阅读器内没有可见的任务进度或版本切换结果，用户无法判断操作是否成功。后端重解析接口保留，不改变已有数据与任务行为。
- 删除“原版”模式：当前实现并未渲染原始 PDF/EPUB 版式，而是复用重排分页，标签与结果不符。
- 删除书签：当前只切换本地视觉状态，未保存、未展示，也没有书签列表入口。

## 范围与边界

只修改阅读页的静态 HTML、CSS、JavaScript 和必要的聚焦测试。不得：

- 修改读取、解析、进度或偏好保存 API；
- 删除后台重解析能力；
- 新增首页、尾页或页码跳转；
- 新增书签持久化、真实原版渲染或音频资源；
- 改变正文分页算法、目录或全文搜索行为。

## 可访问性与响应式

- 所有保留按钮都有明确的 `aria-label` 和键盘焦点状态。
- 音频播放状态通过 `aria-pressed` 或等价的状态语义暴露给辅助技术。
- 小屏幕保持搜索、背景音和 `Aa` 三个入口；标题优先截断而不是挤压或换行。
- 现有键盘翻页、Esc 关闭面板和工具栏显隐行为不得回归。

## 验收与验证

1. 阅读器工具栏只显示返回、目录、搜索、背景音、`Aa` 五类控件；原版、书签、重新解析均不可见。
2. 背景音面板可选择三条现有音轨并调整音量，选项和音量仍保存到既有阅读偏好。
3. 搜索、目录、字体、主题、单双页和前后翻页继续可用。
4. 现有阅读页静态资产与行为单元测试通过；新增或调整测试只覆盖这次变更。
5. 通过 8000 服务进行一次浏览器验收，控制台无前端错误。
